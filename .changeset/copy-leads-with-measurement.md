The copy now leads with the measurement, states the abstention as an answer, and discloses what leaves the machine.

Three user-facing surfaces change; nothing on the wire does.

- **The `estimate` tool description.** It promised a token range unconditionally, so a model told it would get a number treats an abstention as a failure — and is then under pressure to re-ask with a rephrased query, which bills a second estimate. The returns sentence now names "no range at all when there is no firm basis to forecast this particular task, which is an honest answer, not an error". The lead also says the stored estimate is what lets the same run's realized spend be *measured* rather than merely *recorded* — the forecast is a probability; the measurement is a count. The final sentence (the live-usage disclaimer) is byte-identical.

- **The void message.** It led with what the product cannot do and carried `(out of domain)` — an internal scenario label — on a public string that reaches users directly. It now reads "No forecast for this task — Budgetary has no firm basis to judge one like it, and won't guess. / This estimate wasn't billed. Proceed on your own judgment — an abstention is an answer, not an error." Per query, never a rate. "This estimate wasn't billed." is unchanged. Everything appended beneath it, and the blank-line seam above that, are untouched.

- **A one-time data disclosure.** Nothing at runtime previously said what this package transmits; it lived only in a README a user had no reason to open. The first successful `estimate` on a machine now appends a one-time note naming both transmissions and pointing at the README's Privacy section, and `doctor` states a short form of it on every run. It is one call late and says so — by the time anything can render, the task text has already been sent. It is a disclosure, not consent: it asks for nothing, gates nothing, grants nothing, and claims no completeness of its own. It never fires on an error path, and a marker that cannot be written degrades to silence rather than a nag.

Existing installs see the disclosure once, on their next estimate. The priced render is byte-unchanged.
